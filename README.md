# Libft
*This activity has been created as part of the 42 curriculum by aselfrie*

## Description:
libft is the first project of the 42 curriculum.
The goal is to recreate a personal C library that contains a collection of essential functions used throughout future 42 projects.
These functions re-implement key features from the standard C library (stdlib.h, string.h, ctype.h) as well as additional utility functions to handle memory, strings, characters, and linked lists.

## Instructions:
To compile the library, run:
make
and for cleanup, run:
make fclean
